Bounded large-parameter HCCL weight transfer

REPORT.md contains the measured results and limitations. acceptance.json records
the requested validation gates. bounded-transfer.patch contains only the feature,
its unit and native E2E tests, and user documentation. The lifecycle baseline is a
separate patch; all A/B/C measurements use that same correctness baseline.

Source pair:
  vllm-ascend 24a76e84394ae3427195e3715fc08e90769d398c
  vllm        544f182d9f0c9bfe8bd7645525951d5e3692a542

Environment:
  Driver 26.1.1; four Ascend 910B2C 64 GiB devices.
  Python 3.12.16; torch 2.10.0+cpu; torch_npu 2.10.0.post4.
  CANN/NNAL 9.2.1; the pinned Ascend A2 Dockerfile's 910B operator packages.
  NumPy 1.26.4; OpenCV headless 4.11.0.86; Triton Ascend 3.2.2.
  installed-requirements.txt lists the complete Python environment.
  Apply vllm-environment.patch to the pinned vLLM dependency requirements.

Apply bounded-transfer.patch to the pinned Ascend checkout. For comparisons also
apply lifecycle-baseline.patch. Build the native extensions for this exact stack
using the pinned repository's A2 recipe. Source the installed CANN and NNAL
set_env.sh files before device commands. Set TORCH_DEVICE_BACKEND_AUTOLOAD=0.
The local workspace uses tools/ascend_env.sh and tools/run_four_card.py for this
host's device admission and keepalive coordination; those host-specific settings
must match the machine running the experiment.

The following commands assume the experiment tools are in ./tools and the paired
repositories are installed in the active Python environment. Immediately before
each NPU job, run npu-smi info and require the selected devices to be healthy and
idle. Device numbers below are logical IDs. These direct commands are suitable
for a reserved machine; this workspace runs them through its coordinator.

CPU tests (no NPU initialization):
  TORCH_DEVICE_BACKEND_AUTOLOAD=0 python -m pytest -q \
    upstream/vllm-ascend/tests/ut/distributed/weight_transfer

Byte-level correctness, one sender plus one receiver:
  python tools/transfer_experiment.py --task bytes --devices 0 1 \
    --bucket-mib 2 --output results/bytes

Memory and timing, three warmups plus 30 balanced samples per A/B/C:
  python tools/transfer_experiment.py --task memory --devices 0 1 \
    --inventory-gib 4 --bucket-mib 128 --largest-mib 2048 \
    --warmup 3 --samples 30 --output results/matrix
  python tools/summarize_transfer.py results/matrix
  Repeat inventory {4,16} GiB and bucket {128,512,2048} MiB.
  Ordinary-size control: inventory 4 GiB, bucket 128 MiB, largest 64 MiB.

Copy-loader pressure:
  Add --modes A --budget-mib 2432 --warmup 0 --samples 1 for baseline OOM.
  Add --modes C --budget-mib 2432 --warmup 0 --samples 10 for bounded updates.
  Use different output directories for every command.

Independent profiler run:
  Add --profile --warmup 3 --samples 1 to a separate memory job.
  Profiling results are excluded from the formal timing samples.

Native large Qwen2, including cold-load byte/inference oracle:
  python tools/native_worker_smoke.py --task prepare --large \
    --directory results/large-model
  python tools/native_worker_smoke.py --task update \
    --model-directory results/large-model --directory results/native-C \
    --mode bounded --slots 2 --updates 33
  python tools/native_worker_smoke.py --task cold \
    --model-directory results/large-model --directory results/native-C
  python tools/native_worker_smoke.py --task compare --directory results/native-C
  Repeat with legacy/2 slots and bounded/1 slot in separate directories.
  --attribution instruments native layer reconstruction and loader retention.
  --headroom-mib 5120 limits the Worker allocator after model initialization.
  Supervise the expected-OOM baseline with a process timeout: a Worker allocation
  failure can leave its sender waiting in HCCL. The local driver ends its own
  supervised process group after the Worker has recorded the allocation OOM.
  --updates 1001 --min-seconds 1800 performs the stability experiment.

TP=2 and ACL graph:
  Prepare without --large for the small deterministic model.
  Add --tp 2 to update, cold and compare (one sender plus two receivers).
  Add --graph to update and cold for FULL_DECODE_ONLY ACL graph.

Four-card extension:
  Use --devices 0 1 2 3 for byte and memory tests.
  On this machine, TP=2 and four-card jobs use:
    HCCL_INTRA_PCIE_ENABLE=0 HCCL_INTRA_ROCE_ENABLE=1
  This setting reflects the machine's HCCS/RoCE topology.

The evidence bundle contains raw JSON measurements, patch files and analysis
tools. Deterministic checkpoints can be regenerated by prepare; large checkpoint
and parameter snapshot files remain in the local experiment directory.
